# Ascension: Rune Masters

![](https://cf.way2muchnoise.eu/versions/1286770.svg) ![](https://img.shields.io/badge/NeoForge-lime?style=plastic&amp;link=https%3A%2F%2Fneoforged.net%2F)

This is an add-on for the Ascension, a Xianxia styled mod that lets you cultivate to Immortality/Godhood.  

This add-on introduces an all new path to the mod, the Runic Path, as well as a Rune Sequence casting system and various items to assist a Rune Master on their
path to Immortality.
